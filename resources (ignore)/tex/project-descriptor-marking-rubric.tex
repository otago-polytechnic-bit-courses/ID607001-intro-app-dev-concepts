\section*{Authenticity}
All parts of your submitted assessment \textbf{must} be completely your work. Do your best to complete this assessment without using  AI tools. You need to demonstrate to the course lecturer that you can meet the learning outcome for this assessment. \\
 
Learning to use AI tools is an important skill. While AI tools are powerful, you \textbf{must} be aware of the following:

\begin{itemize}
    \item If you provide an AI tool with a prompt that is not refined enough, it may generate a not-so-useful response
    \item Do not trust the AI tool's responses blindly. You \textbf{must} still use your judgement and may need to do additional research to determine if the response is correct
    \item Acknowledge what AI tool you have used. In the assessment's repository \textbf{README.md} file, please include what prompt(s) you provided to the AI tool and how you used the response(s) to help you with your work
\end{itemize}

It also applies to code snippets retrieved from \textbf{StackOverflow} and \textbf{GitHub}. \\
 
Failure to do this may result in a mark of \textbf{zero} for this assessment.

\section*{Instructions}

\subsection*{Functionality - Learning Outcome 1 (25\%)}
\begin{itemize}
	 \item Backend application with the following functionality:
	 \begin{itemize}
	 	\item Five \textbf{models} with a minimum of four \textbf{fields}.
		\item One model should have an enum field.
	 	\item One \textbf{one-to-many} relationship and one \textbf{many-to-many} relationship.
	 	\item \textbf{CRUD} operations for each model.
	 	\item Validation on \textbf{Create} and \textbf{Update} operations.
	 	\item \textbf{Filter}, \textbf{sort} and \textbf{paginate} using \textbf{query parameters}.
	 	\item Allow users to register, login and logout.
		\item Role-based access control:
		\begin{itemize}
			\item An \textbf{admin user} can perform \textbf{CRUD} operations on all \textbf{models}.
			\item A \textbf{normal user} can perform \textbf{Read all} and \textbf{Read by UUID} operations on all \textbf{models}. 
		\end{itemize}
		\item Content negotiation to support \textbf{JSON} format.
		\item Seed script to populate the database with initial data.
		\item API tests covering \textbf{CRUD} operations for each model.
		\item Deploy to \textbf{Render}.
	 \end{itemize}

	 \item Frontend application with the following functionality:
	 \begin{itemize}
		 \item Consume the backend application on \textbf{Render} to perform \textbf{CRUD} operations based on role.
         \item Styled using \textbf{Bootstrap}.
		 \item Authentication with secure token handling.
		 \item Display data with support for \textbf{filtering}, \textbf{sorting} and \textbf{paging}.
		 \item Forms with validation for \textbf{Create} and \textbf{Update} operations.
		 \item Render UI elements and actions based on role.
		 \item Ten end-to-end tests covering the main features.
		 \item Deploy to \textbf{Vercel}.
	 \end{itemize}
\end{itemize}

\subsection*{Code Quality and Best Practices - Learning Outcome 1 (40\%)}
\begin{itemize}
	\item Write clean, readable and maintainable code.
	\item Use modular, reusable components and avoid code duplication.
	\item Keep code simple and easy to understand.
	\item Optimise performance by managing resources efficiently.
\end{itemize}

\subsection*{Version Control - Learning Outcome 1 (5\%)}
\begin{itemize}
  \item Regular commits are made throughout development, demonstrating meaningful progress.
  \item Commit messages are clear and descriptive.
  \item The repository shows a clean and logical commit history that reflects the development process of the applications.
\end{itemize} 

\subsection*{Reflection - Learning Outcome 1 (5\%)}
\begin{itemize}
  \item Write a short reflection (300-500 words) on your development process and learning throughout the project, including:
  \begin{itemize}
    \item Challenges you faced and how you overcame them.
    \item What you would do differently in future projects.
    \item New skills, tools or practices you learned during the project.
  \end{itemize}
\end{itemize}

\subsection*{Presentation - Learning Outcome 1 (5\%)}
\begin{itemize}
  \item Record a 5-10 minute screen recording of your applications.
  \item Demonstrate the backend and frontend features.
  \item Make sure the video is clear and easy to follow.
  \item Submit a link to the presentation in your repository's \textbf{README.md} file.
\end{itemize}
